# API Documentation

This section provides a detailed reference for all namespaces and classes within the **dosymep.Autodesk** suite.

## Namespaces

- **dosymep.AutodeskApps**: Core shared logic and base interfaces.
- **dosymep.AutodeskApps.FileInfo**: Generic file information handling.
- **dosymep.Revit.FileInfo**: Revit-specific metadata extraction (`BasicFileInfo`, `TransmissionData`, etc.).
- **dosymep.Navisworks.FileInfo**: Navisworks-specific metadata extraction.
- **dosymep.Revit.Journaling**: Utilities for creating and parsing Revit journals.
- **dosymep.Revit.ServerClient**: REST API client for interacting with Revit Server.
