# dosymep.Autodesk

[![JetBrains Rider](https://img.shields.io/badge/JetBrains-Rider-blue.svg)](https://www.jetbrains.com/rider)
[![License MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://en.wikipedia.org/wiki/MIT_License)

Welcome to the documentation for **dosymep.Autodesk**, a collection of .NET libraries designed to streamline development for Autodesk products like Revit and Navisworks.

## Overview

This project provides several independent but related modules to handle various aspects of Autodesk software interaction:

*   **FileInfo**: Extract metadata and previews from `.rvt`, `.rfa`, and Navisworks files efficiently.
*   **Journaling**: Automate Revit operations by generating and modifying journal files.
*   **Revit Server**: Programmatically manage models and folders on Revit Server.
